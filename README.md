## Overview

Arturia MiniFreak combines digital oscillator engines with analog filters and effects in a compact 37-key instrument, offering innovative synthesis including Karplus-Strong, wavetable, and virtual analog.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia MiniFreak** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Digital Oscillators** | Over 20 oscillator engine types including wavetable, FM, and modal |
| **Analog Filter** | Analog low-pass filter preserving warmth in the digital signal chain |
| **Spice/Dice** | Two macro knobs randomize parameters for instant creative variation |
| **Sequencer/Arp** | 32-step sequence with per-step probability, pitch, and motion recording |
